# Blueprint 2.0.0

Blueprint turns an idea into a reviewed, testable project plan inside the conversation. The V2 keeps the original conversational approach and adds deeper discovery, references/pre-design, MVP, architecture, data/API, security, tests, decisions and agent handoff.

Included: installable Agent Skills folder, FR/EN documentation/templates, optional JSON schema, offline export/checking tools and synthetic examples. No abandoned website, backend, credentials or required runtime.

Install with `npx skills add SimonBitton/blueprint --skill blueprint`, or copy `skills/blueprint` into your host's skills directory after preserving an existing version. Skills CLI telemetry belongs to the CLI; `DISABLE_TELEMETRY=1` opts out.

The validation report distinguishes executed checks from remaining host/model limits. This release is not a security certification or universal model-compatibility claim. Review exports before sharing; host privacy and retention remain outside the skill.

MIT license. Archives and SHA-256 sums accompany the release. See README and docs for usage, migration and limitations.
