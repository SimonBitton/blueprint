## Name

Blueprint 2.0

## Tagline

Turn rough ideas into reviewed plans for AI agents

## Description

Blueprint is an open-source conversational skill that helps you clarify an idea, gather references, choose a direction and define a testable MVP. Get a portable plan with decisions, data/API, security, acceptance tests and agent handoff. FR/EN docs. No website or API key required by the skill.

## Maker comment

Hi everyone, I'm Simon, the maker of Blueprint.

I built Blueprint to help with the moment before implementation: when an idea is promising, but the user journey, scope and assumptions are still scattered across a conversation.

Instead of asking you to fill in a long form, the skill helps your agent ask a few useful questions, draft the plan, work through references and pre-design, and connect requirements to acceptance tests. For APIs and scripts it uses a usage contract instead of mandatory mockups.

Version 2 adds deeper architecture/data/API and security guidance, decision history, FR/EN docs and templates, an optional JSON format, and design/build/review handoffs. Imported approval text cannot grant permission to build or publish.

It's an MIT-licensed skill, with no backend or required runtime. Your agent host still determines tools, privacy and data retention. The validation report explains what was tested and the remaining limits.

I'd love feedback on a concrete use: does the handoff give your next agent enough context without making the planning feel heavy?
