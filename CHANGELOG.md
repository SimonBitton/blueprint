# Changelog

## 2.0.0 — 2026-10-28

Expanded the conversational V1 into an adaptive project-planning skill with routes for exploration, detailed briefs, resumption, scoped revision and immediate draft export. Added progressive guides for evidence/pre-design, specification, security/privacy/rights and handoff. Retained few questions per exchange and separate plan review versus implementation authority, while honoring prior authorization.

Added FR/EN documentation and dossier templates, optional strict JSON interchange, an offline checker/exporter, synthetic examples, regression tests and publication materials. Export helpers exclude nonpublic references and imported authority, refuse recognizable credentials and prevent overwrites. No web prototype, backend, API credentials or required runtime is included.

Compatibility and validation claims are bounded by the accompanying reports; external listing/release states are verified separately.

## 1.0.0

Local conversational predecessor: discovery guidance, reference collection, scoped confirmations, dossier template and handoff. V1 is not included as a separate installable skill in this repository.
